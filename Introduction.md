Welcome to the Openshift Platform's **Launch Workshop** by Red Hat.

This workshop will help you start your journey toward the development and management of containerized applications on the Red Hat Openshift Container Platform.

The workshop will show you how to take an application and have it run and monitored on your Openshift cluster.

Several applications can be used: 

*   Existing JEE7 monolith (to come)
*   Existing EAP 7 monolith
*   Existing Spring monolith
*   New Quarkus microservice (to come)
*   New Springboot microservice (to come)

From a high level overview, here are the topics covered during the workshop:

*   Building an existing application
    *   Using S2I source
    *   Using S2I binary
    *   Using docker/podman
    *   Using Helm
    *   Using Templates
*   Image security and capabilities
    *   Kubernetes images
    *   Openshift images
    *   Red Hat Openshift images
*   Deploying a built application
    *   Using the Web Console
    *   Using Helm
    *   Using Templates
    *   Using Tekton
    *   Using ArgoCD
*   Managing the applications resources
    *   Environment variables
    *   Configuration files
    *   Using the filesystem
    *   Stateful applications
*   Troubleshooting containers
    *   Logs
    *   Debugging
    *   Inspection
*   Monitoring
    *   Metrics
    *   Alerts
    *   Resource management
    *   Application observability
